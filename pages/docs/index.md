# Documentation

These pages provide technical details on webpack's API.

- [Webpack](/docs/api) — Every configuration option and every type in webpack's public API, generated from the source.
- [Loaders](/docs/loaders) — Third-party loaders that process CSS, TypeScript, images, and other file types.
- [Plugins](/docs/plugins) — Community plugins that extend webpack for build optimization, asset management, and more.

Looking for the command line instead? That is covered in the guides, starting with [Using the Command Line](/guides/cli).
